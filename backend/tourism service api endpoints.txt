Get Hotel Booking Details
Endpoint: GET /hotel-bookings/:bookingId
Description: Get specific hotel booking details.
Example Request: GET /hotel-bookings/607f1f77bcf86cd799439103



Update Hotel Booking
Endpoint: PUT /hotel-bookings/:bookingId
Description: Update hotel booking details (only if status is pending).
Example Request Body:
JSON
{
  "numberOfGuests": 3,
  "specialRequests": "Updated requests: need an extra bed."
}





Cancel Hotel Booking
Endpoint: POST /hotel-bookings/:bookingId/cancel
Description: Cancel a hotel booking.
Example Request Body:
JSON
{
  "reason": "Plans changed, no longer need the hotel."
}





 Check In
Endpoint: POST /hotel-bookings/:bookingId/check-in
Description: Check in to the hotel.
Example Request: POST /hotel-bookings/607f1f77bcf86cd799439103/check-in


 Check Out
Endpoint: POST /hotel-bookings/:bookingId/check-out
Description: Check out from the hotel.
Example Request: POST /hotel-bookings/607f1f77bcf86cd799439103/check-out

3. Get Guide Reviews
Endpoint: GET /reviews/guides/:guideId
Description: Get all reviews for a specific guide.
Query Parameters (Optional):
page: Integer (default: 1)
limit: Integer (default: 10)
sort: String (e.g., -createdAt for descending)
Example Request: GET /reviews/guides/507f1f77bcf86cd799439020?page=1&limit=5



4. Get Hotel Reviews
Endpoint: GET /reviews/hotels/:hotelId
Description: Get all reviews for a specific hotel.
Query Parameters (Optional):
page: Integer (default: 1)
limit: Integer (default: 10)
sort: String (e.g., -createdAt for descending)
Example Request: GET /reviews/hotels/507f1f77bcf86cd799439030?sort=-rating



5. Update Review
Endpoint: PUT /reviews/:reviewId
Description: Update an existing review.
Example Request Body:

JSON


{
  "rating": 5,
  "comment": "Absolutely fantastic experience, even better than expected!"
}





6. Delete Review
Endpoint: DELETE /reviews/:reviewId
Description: Delete a review.
Example Request: DELETE /reviews/607f1f77bcf86cd799439201


7. Add Review Response
Endpoint: POST /reviews/:reviewId/response
Description: Add a response to a review (for guide/hotel management).
Example Request Body:

JSON
{
  "responseText": "Thank you for your valuable feedback! We are glad you enjoyed your stay."
}
