# SMART TOURIST PLATFORM - TOURIST API TESTING FLOW

====================================================

1. REGISTER TOURIST
   ====================================================

POST http://localhost/api/auth/register

{
"nic": "200112345678",
"email": "[tourist1@example.com](mailto:tourist1@example.com)",
"password": "Password@123",
"confirmPassword": "Password@123",
"name": "John Doe",
"role": "TOURIST",
"phone": "+94771234567",
"bio": "I love traveling around Sri Lanka.",
"avatarUrl": "https://example.com/avatar.jpg"
}

---

2. LOGIN

POST http://localhost/api/auth/login

{
"email": "[tourist1@example.com](mailto:tourist1@example.com)",
"password": "Password@123"
}

Save the accessToken.

---

3. GET USER PROFILE

GET http://localhost/api/users/me

Header:
Authorization: Bearer <accessToken>

---

4. UPDATE USER PROFILE

PUT http://localhost/api/users/me

Header:
Authorization: Bearer <accessToken>

{
"name": "John Snow",
"phone": "+94771234567",
"bio": "Love traveling in Sri Lanka.",
"avatarUrl": "https://example.com/new-avatar.jpg"
}

---

5. GET TOURIST PROFILE

11. CREATE TRIP

POST http://localhost/api/trips

Header:
Authorization: Bearer <accessToken>

{
"title": "Sri Lanka Adventure Trip",
"description": "Exploring beaches and mountains",
"startDate": "2026-07-01",
"endDate": "2026-07-10",
"budget": 1500,
"currency": "USD",
"isPublic": true,
"destinations": [
{
"name": "Colombo",
"country": "Sri Lanka",
"coordinates": [79.8612, 6.9271],
"visitOrder": 1
},
{
"name": "Kandy",
"country": "Sri Lanka",
"coordinates": [80.6337, 7.2906],
"visitOrder": 2
}
]
}

Save the tripId.
